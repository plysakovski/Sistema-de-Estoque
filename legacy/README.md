# Protótipo legado

Esta pasta preserva a primeira prova de conceito do StockManager Pro, construída com HTML, JavaScript, um servidor Python local e planilhas Excel.

Ela existe para registrar a evolução do projeto e auxiliar migrações. Não possui os controles atuais de autenticação, autorização, criptografia e integridade transacional; portanto, não deve ser exposta em rede nem utilizada com dados reais.

As planilhas versionadas contêm somente dados demonstrativos. O desenvolvimento atual acontece em [`apps/desktop/`](../apps/desktop/README.md).
