# Sistema visual

Conceito: [dashboard-concept.png](design/dashboard-concept.png).

- Fundo grafite quase preto, superfícies carvão e bordas finas.
- Verde esmeralda para ações e estados operacionais; âmbar/vermelho só para alertas.
- Sans-serif do sistema para leitura e Cascadia Code/Consolas em marcadores de terminal.
- Densidade de ferramenta profissional: tabelas e listas permanecem o elemento principal.
- Raios de 7–10 px, sombras discretas, ícones lineares de peso consistente.
- Foco visível, contraste alto, movimento reduzido quando solicitado pelo sistema.
